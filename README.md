# static-maker
A program that generates images resembling tv static. I started making this to create assets for a game I'm working on, but as I spent longer and longer working on it (around a full month), I decided it should be public, just in case there's anyone else like me.
Before you judge my code too harshly, remember I'm a teenager and this is the first thing I've ever made in c++. I'm well aware that it's bad, but I refuse to spend any more time on this. I'm finally free from the hell that was the development process. Maybe now I can finally finish Chrono Trigger.

A small note for compiling: I couldn't get it to work with gcc. I'm not sure exactly why it wasn't working (I don't think I've ever compiled anything outside of an IDE) but the only way I could get it to actually write the CRC32s was inside code::blocks. So if it's not working for you, I'd recommend you try that. That's also the reason why I can't provide a binary.
